HDR → SDR Screenshot Collapse Lab

Safari 真机实验 · 目标：寻找“原屏清晰、SDR 截图不可读”的亮度窗口。
测试前：iPhone 设置 → 通用 → 屏幕捕捉 → 格式 → SDR。然后必须用 Safari 直接打开这个 HTTPS 页面。
A · HDR / no-limit

真正的 10-bit PQ / BT.2020 AVIF。背景固定约 203 nit；文字从 203 nit 扫到 1000 nit。

B · 同一 HDR 文件 / standard

同一个 AVIF，但要求 WebKit 把动态范围限制到 standard。用于和 A 肉眼比较。

C · 普通 SDR 基准

下面不是 HDR，只用普通网页颜色。它用于确认截图、缩放和字体本身没有异常。

SDR 基准：明天八点门口见

判定

只记录同时满足以下条件的亮度档：

  1. A 在 iPhone 原屏上无需费力即可阅读；
  2. B 明显比 A 弱，证明 HDR headroom 确实参与显示；
  3. 系统 SDR 截图的 A 中，同一档文字消失或严重接近背景；
  4. 把截图放大后仍无法恢复。

如果截图中的 A 与原屏观感基本一致，则 HDR 路线淘汰。若只在某个范围出现坍缩，下一轮再围绕该范围做更细的 nit 扫描。
